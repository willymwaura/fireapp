# Fire Reporting and Response System

The Fire Reporting and Response System is a comprehensive web application designed to facilitate the reporting and response to fire incidents. This system enables users to report fires, notifies nearby fire stations, and optimizes the response process for efficient and timely actions.

## Features

- **Fire Reporting:** Users can report fires by providing coordinates and optional additional information.
- **Notification System:** SMS notifications are sent to the nearest fire station upon receiving a fire report.
- **Official Confirmation:** Officials can confirm reported fires and manage notifications.
- **Station Member Notifications:** Station members receive SMS notifications with a Google Maps link for detailed fire information.
- **Location Details and Route Optimization:** Users can view detailed location information, and the system provides the best route from the fire station to the reported fire.
- **Fire Heat Map:** The website displays a heat map based on reported fire incidents.
- **Fire Precaution Measures:** Information on fire precaution measures is provided on the website.


## Languages and Tools Used

- **Django:** Web framework for building the application.
- **HTML, CSS, JavaScript:** Frontend technologies for user interface.
- **Postegresql:** Database management system.
- **SMS APIs:** Used for sending notifications.
- **Google Maps API:** Integrated for location-related features.
